# Open Space — Cognitive Integration & Awareness

An invitational, trauma-informed web application for contemplative practice, somatic grounding, and right-hemisphere attentional exploration. Synthesizes Dr. Daniel P. Brown's gradual Mahamudra framework, Dr. Iain McGilchrist's hemisphere-attention research, and somatic vagal regulation practices.

## Key Features

- **5-Stage Guided Mahamudra Practice**: Invitational timers, stage-matched Web Audio ambient frequencies, non-judgmental inquiry prompts, and post-session reflections.
- **Interactive Right-Hemisphere Shift**: Visual perception toggle and attentional field sliders inspired by Dr. Iain McGilchrist.
- **Restorative Breath & Procedural Soundscapes**: 4-7-8 Restorative Unwinding, 4-6 Gentle Flow, and 4-4-4-4 Grounding Box breath pacers paired with pure client-side Web Audio synthesis (Forest Stream, Alpine Breeze, Singing Bowl, Grounding Drone).
- **5-4-3-2-1 Grounding & Orientation Pause**: Instant trauma-informed sensory orientation modal accessible from anywhere in the space.
- **Private Local Reflective Notes**: Stored strictly in browser `localStorage` with one-click JSON export—zero external API calls, zero tracking, and zero cloud AI costs.
