# Quiet Ground — Somatic Ease & Open Awareness

An invitational, trauma-informed web application for contemplative practice, somatic grounding, and right-hemisphere attentional exploration. Synthesizes Dr. Daniel P. Brown's gradual Mahamudra framework, Dr. Iain McGilchrist's hemisphere-attention research, and trauma-sensitive somatic vagal regulation practices.

## Key Features

- **5-Stage Guided Mahamudra Practice**: Invitational timers, warm low-register Web Audio acoustic drones (A2–G3), hands-free prompt progression, and post-session reflections.
- **Interactive Right-Hemisphere Shift**: Visual perception toggle plus live Width of Field and Somatic Grounding sliders inspired by Dr. Iain McGilchrist.
- **Restorative Breath & Procedural Soundscapes**: Trauma-safe 4-6 Gentle Flow default (zero breath-hold), 4-4-4-4 Grounding Box, and 4-7-8 Restorative Unwinding paired with pure client-side Web Audio synthesis (Forest Stream, Alpine Breeze, Singing Bowl, Grounding Drone).
- **5-4-3-2-1 Grounding & Orientation Pause**: Native `<dialog>` sensory orientation pause accessible from anywhere in the app.
- **Private Local Reflective Notes**: Stored strictly in browser `localStorage` with one-click JSON export—zero external API calls, zero tracking, and zero cloud AI costs.
